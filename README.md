# ☕ Kape ni Lola — Tarlac City Café Website

> A warm, story-driven café website built as a group web development project.

---

## 📌 Project Overview

**Kape ni Lola** is a multi-page static website for a fictional family café based in Tarlac City. The site features a homepage with menu previews, an about page with the café's backstory and team, and a contact page with a reservation form. The project emphasizes visual storytelling, smooth animations, and a cohesive warm aesthetic inspired by Filipino café culture.

## ✨ Features

- **Responsive multi-page layout** with smooth fade transitions between pages
- **Hero parallax effect** — background image shifts subtly on scroll
- **Scroll-triggered reveal animations** — elements fade and slide in as you scroll
- **Animated stat counters** — numbers count up on page load
- **Steam particle animation** on the hero section
- **Real café photography** sourced from Unsplash (free license)
- **Hover micro-interactions** on cards, menu items, navigation, and contact icons
- **Functional contact form** with a submission feedback state
- **Fixed navigation bar** with scroll shadow and active link indicator

## 🚀 How to Run

1. Download or clone this repository.
2. Open `kape-ni-lola-v2.html` in any modern web browser (Chrome, Firefox, Edge, Safari).
3. No build steps, no installs — it runs entirely in the browser.

> **Note:** The site loads images from Unsplash via URL. An internet connection is required to display photos.

---

## 🎨 Design Decisions

- **Color palette** built around deep coffee browns, warm creams, and tan gold — evoking the café's cozy atmosphere.
- **Typography** uses Playfair Display (serif) for headings to add elegance, paired with Lato (sans-serif) for readable body text.
- **Page transitions** use a dark overlay fade so switching between pages feels deliberate and cinematic rather than abrupt.
- **Animations** are kept subtle and purposeful — nothing distracts from the content.
